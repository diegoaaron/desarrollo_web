6. CASOS DE ERROR PARA PROBAR (y la respuesta esperada)
-------------------------------------------------------
  400 · Cotizar con el carrito vacío (POST /api/quotes sin líneas)
  400 · Subir un archivo que no es imagen (p. ej. un .svg o .gif) o una imagen de más de 5 MB
  400 · Cantidad 0 o negativa; teléfono con letras; CVV de 2 dígitos
  404 · Un cliente pide el pedido o la notificación de otro cliente
  409 · Pedir más unidades que el stock de una talla:
        "Stock insuficiente para POLO-...-S (S, Blanco): pediste 21"
  422 · Bordado en ESPALDA: "La zona ESPALDA no admite bordado..."
  422 · El admin intenta pasar un pedido de PAGADO a ENTREGADO (salto de estados)
  422 · El admin intenta marcar un pedido como PAGADO (solo lo hace un pago aprobado)


7. VALORES QUE USAN LAS PRUEBAS UNITARIAS (44 pruebas, JUnit 5)
---------------------------------------------------------------
QuantityPolicyTest (escala que corresponde a cada cantidad):
  1->1 · 2->1 · 3->3 · 4->3 · 5->3 · 6->6 · 9->6 · 11->6 · 12->12 · 15->12 · 100->12
  0 y -1 -> error de regla de negocio

LineAmountsTest (importes de una línea):
  base 35.00 + extras 23.00, 12 u., 15 %  -> unitario 58.00, bruto 696.00, descuento 104.40, total 591.60
  base 10.15, 3 u., 5 %                   -> bruto 30.45, descuento 1.52, total 28.93
  base 19.99 + extras 4.01, 7 u., 10 %    -> total = bruto - descuento, siempre con 2 decimales

OrderStatusPolicyTest (máquina de estados):
  Permitidas: PENDIENTE_PAGO->PAGADO · PENDIENTE_PAGO->CANCELADO · PAGADO->EN_PRODUCCION
              PAGADO->CANCELADO · EN_PRODUCCION->LISTO_PARA_ENVIO · LISTO_PARA_ENVIO->ENVIADO
              ENVIADO->ENTREGADO
  Rechazadas: PENDIENTE_PAGO->ENVIADO · PAGADO->ENTREGADO · EN_PRODUCCION->CANCELADO
              ENVIADO->PAGADO · ENTREGADO->CANCELADO · CANCELADO->PAGADO · PAGADO->PAGADO
  Solo CANCELADO repone el stock.

OrderStatusChangedDeliveryTest (evento de dominio):
